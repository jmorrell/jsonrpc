## End-to-End: Full Bidirectional RPC Lifecycle

**Purpose:** Validate the entire flow from session creation through bidirectional calls to graceful shutdown.

1. Create two linked transports using `createLinkedTransports()`.
2. Create `sessionA` as initiator with a local service `{ ping(): Promise<string> { return Promise.resolve("pong") } }`.
3. Create `sessionB` as acceptor with a local service `{ echo(v: string): Promise<string> { return Promise.resolve(v) } }`.
4. From `sessionA`, call `sessionA.remote.echo("hello")`. Verify result is `"hello"`.
5. From `sessionB`, call `sessionB.remote.ping()`. Verify result is `"pong"`.
6. From `sessionA`, start a call to a method that never resolves on session B.
7. Call `sessionA.close()`.
8. Verify the pending call from step 6 rejects with `"Session closed"`.
9. Verify that `sessionA.remote.anyMethod()` rejects immediately with `"Session is closed"`.
10. Close `sessionB` to clean up.

## End-to-End: Error Recovery Sequence

**Purpose:** Validate the session survives a sequence of error conditions and continues serving requests.

1. Create linked transports and sessions (initiator + acceptor with an `echo` service).
2. Inject malformed JSON via `transportB.send("{{bad")`. Verify `onError` fires with a `SyntaxError`.
3. Inject a response with unknown ID via `transportB.send(JSON.stringify({ jsonrpc: "2.0", id: 99999, result: "x" }))`. Verify `onError` fires.
4. Inject an unroutable message via `transportB.send(JSON.stringify({ jsonrpc: "2.0", foo: "bar" }))`. Verify `onError` fires.
5. Inject a notification via `transportB.send(JSON.stringify({ jsonrpc: "2.0", method: "echo" }))`. Verify `onError` fires and handler was not called.
6. Make a normal call `sessionA.remote.echo("still works")`. Verify result is `"still works"`.
7. Close both sessions.
